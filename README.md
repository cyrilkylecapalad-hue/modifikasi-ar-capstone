Modifikasi AR – Capstone Project

Modifikasi AR is an academic capstone project exploring Augmented Reality (AR) technology and interactive digital experiences.

Technologies Used

Unity

C#

Augmented Reality (AR)

Project Features

Interactive AR experience

Integration of digital elements into a real-world environment

Unity-based application development

How to Open

Clone or download this repository.

Open the project folder through Unity Hub using a compatible Unity version.

Allow Unity to import the project assets.
